# Vivo助手 隐私政策

**更新日期：2026-09-06**

「Vivo助手」（以下简称"本应用"）是一款免费开源的 ROOT 玩机工具箱，所有功能脚本均在您的设备本地执行，本应用自身不收集、不上传您的任何个人数据。

由于本应用集成了 Google AdMob 广告服务以维持持续开发，在使用广告功能时会涉及以下数据处理。请您在使用前仔细阅读本政策。

## 一、我们收集的信息

本应用自身**不收集**任何个人信息。

第三方广告服务（Google AdMob）在广告展示过程中可能收集：

| 信息类型 | 用途 |
|---------|------|
| 设备标识符（如广告 ID/Android ID） | 广告频次控制、反作弊 |
| IP 地址、粗略地理位置（基于 IP） | 广告地域投放 |
| 设备型号、系统版本、屏幕尺寸 | 广告适配 |
| 广告交互数据（展示/点击） | 效果统计、结算 |

## 二、信息的使用与共享

- 上述信息由 Google AdMob 按 [Google 隐私政策](https://policies.google.com/privacy) 处理，本应用不接触、不存储这些数据。
- 本应用的所有脚本命令均通过本地 ROOT Shell 执行，执行内容与结果不会上传至任何服务器。

## 三、您的选择

- **不同意隐私政策**：首次启动弹窗中选择「不同意」，本应用将完全不初始化广告 SDK，全部功能不受影响。
- **开屏广告频控**：开屏广告每日最多展示 2 次，且两次间隔不少于 6 小时。
- **广告位说明**：广告仅出现在启动开屏与「更多」页横幅位置，任何脚本操作流程中不会出现广告。
- 您也可以在系统设置中重置或关闭广告 ID（设置 → Google → 广告）。

## 四、未成年人保护

本应用面向刷机/玩机爱好者，不面向 14 周岁以下儿童，不会向儿童定向投放广告。

## 五、政策更新

本政策如有重大变更，将通过应用更新公告告知。
